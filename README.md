# Webshop Categories API

Enhanced API endpoints for ERPNext Webshop categories with image support.

## Features

- **Enhanced Product Filter API**: Overrides the original webshop API with category images and metadata
- **Category Tree API**: Hierarchical category structure with images
- **Category Details API**: Detailed information about specific categories
- **Category Search API**: Search categories by name
- **Breadcrumb API**: Navigation breadcrumbs for categories
